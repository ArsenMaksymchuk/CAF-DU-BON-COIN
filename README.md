# Café du Bon Coin — сайт (Нанси)

Многоязычный сайт брассери: 1 Rue Sergent Blandan, 54000 Nancy, тел. 03 54 95 27 80.

- Один файл `index.html` (фото встроены, небольшие), без сборки
- Языки: FR (по умолчанию), EN, DE, IT, ES — переключатель в шапке
- График (пн–пт 8–19, сб 8–18:30, вс закрыто) + статус «открыто/закрыто» по времени Парижа
- Меню «на ардуазе»: plat du jour, Salade César, steak végétal & frites, пиво
- Мини-карта (схематичная, SVG) + кнопка «Открыть в Google Maps»
- Логотип-велосипед (inline SVG, колёса крутятся при наведении)
- 3D на three.js r128: велосипед, пивная кружка, тарелка с салатом
- Эффект кнопок: при наведении из кнопки вылетают 3D-предметы (кружка, картошка фри, колесо, помидор, яйцо)

## Как менять
Тексты — объект `T` (fr в самом HTML, `data-i`). Часы — массив `H`. Меню — блок `.menu`.

## Проверить
Полного меню и цен нет — добавить по фото меню. Карта схематичная (не в масштабе). Ссылка на Facebook не добавлена (нет точного URL). Права на фото (Google Maps).
